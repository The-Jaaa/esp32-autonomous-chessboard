# Bill of Materials

This list captures the principal parts used in the demonstrated prototype.
Quantities do not include workshop spares.

## Control And Sensing

| Component | Quantity |
| --- | ---: |
| ESP32-S3 N16R8 development board | 1 |
| CD74HC4067 16-channel multiplexer | 4 |
| A3144 Hall-effect sensor | 64 |
| 4-channel bidirectional logic-level shifter | 1 |

| Component | Quantity |
| --- | ---: |
| NEMA17 stepper motor | 2 |

| Limit switch | 2 |
| 12 V, 15 kg electromagnet | 1 |
| 15 A dual MOSFET driver module | 1 |

| --- | ---: |

- 10-core ribbon cable for sensor-to-PCB connections

- Veroboard, prototyping board, hookup wire, and strain relief
